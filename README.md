# Personal Portfolio Website

## Project Description

A full-stack personal portfolio website developed to showcase
my education, technical skills, projects and contact information.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Features

- Responsive portfolio design
- About section
- Skills section
- Projects section
- Education section
- Contact form
- Backend API
- MongoDB data storage

## Project Structure

frontend/
backend/

## How to Run

1. Install Node.js
2. Install backend dependencies
3. Configure MongoDB
4. Start the backend
5. Open the frontend
